## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Smook-e/apple-iphone-Clone.git
```

Go into the project folder:

```bash
cd apple-iphone-Clone
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
